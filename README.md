# map_solver

ROS 2 Humble `ament_cmake` package for C++ 2d-lidar scan matching and 

## Description

This package provides command line (offline) tools for processing stationary robot lidar
scans into high-quality occupancy maps via scan-matching followed by GTSAM optimization and
occupancy map extraction.
